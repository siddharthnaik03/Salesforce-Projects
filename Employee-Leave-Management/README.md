# Employee Leave Management System
### Project Description
Developed an Employee Leave Management Portal using Salesforce Experience Cloud to streamline leave application, approval, and tracking processes. Employees can submit leave requests, view leave balances, and track request status, while HR managers can review, approve, or reject leave requests through a centralized portal. Automated notifications and approval workflows improve communication and reduce manual effort.

•	Developed a Leave Management System using Salesforce to automate employee leave request and approval processes.

•	Imported employee records from Excel sheets into Salesforce using Data Import Wizard.

•	Created custom objects such as Employee and Leave Request to manage employee leave details efficiently.

•	Configured approval processes where leave requests are routed to managers for approval or rejection.

•	Implemented automated email notifications to inform employees about leave approval status.

•	Built Salesforce Flows to automatically update employee leave balances after manager approval.

### Technologies Used

•	Salesforce Administration 
•	Experience Cloud 
•	Flow Builder 
•	Approval Process 
•	Custom Objects & Relationships 
•	Email Alerts & Templates 
•	Profiles & Permission Sets 

### Project Outcome
Successfully implemented a self-service leave management portal that reduced manual leave tracking, automated approval workflows, improved communication through email notifications, and provided secure access for employees and HR personnel. This resulted in faster leave processing and enhanced employee experience.
