# TelMed Consultation
### Project Description:
Developed a Telemedicine Consultation Portal using Salesforce Experience Cloud to enable patients and healthcare providers to manage virtual healthcare services efficiently. The portal allows patients to register, schedule appointments, submit consultation requests, and view medical records, while doctors can manage appointments, update consultation details, and monitor patient information through a secure platform.

### Key Responsibilities:
•	Configured custom objects, fields, page layouts, and validation rules. 

•	Built patient and doctor management modules using Salesforce Administration. 

•	Developed automated workflows and approval processes using Flow Builder. 

•	Configured user profiles, permission sets, and role hierarchy for secure data access. 

•	Customized Experience Cloud pages for patient and healthcare provider users. 

•	Implemented record-level security using sharing rules and organization-wide defaults. 

•	Configured automated email notifications using Salesforce Flow and Email Alerts.

### Technologies Used:

•	Salesforce Administration 

•	Experience Cloud 

•	Flow Builder 

•	Profiles & Permission Sets 

•	Custom Objects & Relationships 

### Project Outcome:
Successfully delivered a user-friendly telemedicine portal that streamlined appointment scheduling, consultation management, and patient record access while ensuring data security and improving operational efficiency.
